# PolyVault

A self-hosted secrets manager written in Go, featuring Shamir's Secret Sharing for secure unsealing.

## Features (Planned)

- Shamir's Secret Sharing for master key splitting
- Key-value secrets storage
- Transit encryption engine
- HMAC-chained audit logging
- Token-based authentication
- HTTP API
- CLI client

## Building

```bash
go build .
```
